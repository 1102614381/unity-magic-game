彦祖 · 第一周任务清单（简单版）

目标：先跑通"数据层 → Unity → 一个会转的方块"这条链路。第一周不做美术、不碰硬件、不急着做大场景。

本周总目标：Python 模拟器 → UDP → Unity 接收 → 一个 3D 方块随魔法棒姿态实时转动。整条链路跑通即可交差。
任务 1

读文档 + 装环境

约半天
  • 打开师姐发的 九轴游戏项目说明.html，重点看「四、游戏流程与四个任务」和「七、验收标准」，理解你要做的 4 个任务：倾斜飞行 / 旋转导航 / 挥动魔法棒 / 空间磁场。
  • 安装 Unity（3D 模板）和 Python 3（若已装则跳过）。
任务 2

跑通模拟器（验证数据层）

约半天
  • 解压师姐发的 3-jiuzhou-yyh-unity.zip，找到里面的 Python 模拟器（imu_simulator_v01.py）。
  • 在命令行运行它（默认 AUTO 模式）。确认本机 127.0.0.1 : 5005 在持续发送 JSON 数据包。
  • 这一步是为了先确认"数据层是好的"，之后 Unity 端出问题就是 Unity 的事，排查更清晰。
任务 3

新建 Unity 工程 + 主场景

约 1 天
  • 新建 3D 项目，命名 《魔法岛大冒险》。
  • 建一个主场景，放：一个地面 Plane + 一个代表魔法棒/角色的基础 Cube/Sphere（先不用美术模型）。
  • 加一个 UI Text 显示收到的 roll / pitch / yaw 数值（仅调试用，后面可删）。
任务 4

接 IMU 数据 + 驱动方块

约 1 天
  • 把师姐给的 IMUReceiver.cs 挂到场景物体上，运行 Unity，确认能实时收到 roll / pitch / yaw。
  • 姿态映射（先用基础旋转即可）：
    roll → 绕 X 轴旋转；pitch → 绕 Z 轴旋转；yaw → 绕 Y 轴旋转。
  • 让那个 Cube 随模拟器姿态转动。然后用键盘模式验证整条链路：
    A/D = roll 左右、W/S = pitch 前后、Q/E = yaw 左右、空格 = shake、R = 回正。
任务 5

提交最小可运行 demo

约半天
  • 把跑通的 Unity 工程截图或录屏，发给师姐确认链路 OK。
  • 确认无误后，再进入「魔法岛 4 个任务」的正式玩法设计。
💡 本周三不碰：① 真实硬件（WT901）；② 漂亮美术/场景；③ 大场景搭建。先把"方块能随姿态转"这件事 100% 跑通。
⚠️ 关于"大模型接入 Unity"：那是后面锦上添花的功能（比如给小孩做语音引导），跟"单九轴实时控制采集数据"这条主线无关。本周先放一边，等核心链路跑通再聊，别让它拖慢进度。
补充

验收自查（任务 4 完成后）

  1. Unity 运行后，UI Text 上的 roll/pitch/yaw 数值持续在变化（模拟器在发）。
  2. 按 A/D，方块明显左右翻；按 W/S 前后翻；按 Q/E 左右转。
  3. 按 R 方块回到水平初始姿态。
  4. 整条链路不需要任何真实硬件即可运行。
